# ffbeast-linux

Linux version of the FFBeast wheel configuration tool. Rewritten to work natively on Linux.

<img width="300" height="506" alt="app" src="https://github.com/user-attachments/assets/8e90d503-3f18-4e4f-9190-e14da16859f4" />

## Installation

No installation required - just download appimage and run it.

[![Download Latest Release](https://img.shields.io/badge/Download-Latest%20AppImage-1DB954?style=for-the-badge)](https://github.com/robke96/ffbeast-linux/releases/latest/download/FFBeastLinux-x86_64.AppImage)


## Alternatives
If you run into issues or lack of features:
* Use the original [FFBeast via Wine](https://ffbeast.github.io/docs/en/downloads_wheel.html)
* Use [webFFBeast on Chromium browser](https://pelukkk.github.io/)
